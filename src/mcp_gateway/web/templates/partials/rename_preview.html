{# What changing the tool prefix would do, rendered while it is being typed. The one field on the settings form whose consequence is invisible from the field itself: a new prefix moves every generated name this server publishes at once, and a client holding one of those names finds out by getting an error. So this asks, as the operator types, and writes nothing. Empty until something has been typed, and empty again when the prefix is the one already stored. There is no fallback for a browser with no script and there does not need to be: the save runs the same check and refuses on the same grounds. #}

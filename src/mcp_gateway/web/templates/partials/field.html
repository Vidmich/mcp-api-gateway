{# One labelled control, in the four shapes the configuration forms need. Macros rather than includes so a caller cannot forget to set the variable one reads, and so the distinction that matters here is structural: ``field`` and ``choice`` take a value and put it back, ``secret`` and ``secret_lines`` have no value parameter at all.
